# Well Monitor (базовый трек) 
 
## Назначение 
Учебный проект: вывод паспорта нефтяной скважины. 
Лабораторная работа № 1 курса «Программирование 
и прототипирование ИТ-решений». 
 
## Требования - Python 3.11 или новее 
 
## Как запустить 
1. Создать виртуальное окружение: 
 
       python -m venv .venv 
 
2. Активировать его: 
 
       .\.venv\Scripts\Activate.ps1 
 
3. Запустить программу: 
 
       $env:PYTHONPATH="src" 
       python -m well_monitor.main 
 
## Выводимые показатели - Название скважины - Месторождение - Глубина, м - Дебит, т/сут
